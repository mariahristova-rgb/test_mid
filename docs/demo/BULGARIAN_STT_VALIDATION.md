Names/date/time correctness are evaluated separately from punctuation/case. “Мария Иванова” was preserved in the known-bg corpus, but the introductory verb was misrecognized; literal name extraction must not include the verb. The isolated fifteen-o'clock phrase failed, and the longer availability phrase became “5 на 10.” No guessed date or time is accepted to conceal this.

The installed Microsoft Ivan comparison is independently retained in artifacts/phase8/windows-voice/stt-results.json. Original 16 kHz clock audio was recognized as “Искам час в 15 часа.” PCMU/8 kHz versions failed with both duplication and bandlimited 8→16 kHz conversion. This isolates narrowband acoustic/model loss; it does not prove Ivan is unusable or that all failures are TTS pronunciation. Human review remains pending.

VAD replay evidence: the old 600 ms window split both booking requests; 1200 ms still split Bulgarian; 1800 ms plus 200 ms bounded pre-roll retained one final for all seven saved fixtures, preserving their nonquiet onset. The synthetic replay is not a replacement for SIP validation.

## Phase 8B measured update — 9 October 2026

Existing multilingual small, CPU/int8/four threads/one worker, explicit bg, no new model or expected-answer prompt. Nine owner-authorized synthetic Ivan waveforms were bandlimited to 8 kHz and PCMU encoded/decoded. Twenty-seven actual inference trials compared existing duplication/beam1, bandlimited upsampling plus 250 ms padding/beam1, and the same padding/beam3. The normal STT service was stopped only during this offline single-worker evaluation, then restored. The first harness invocation failed before inference due an import path; this was corrected and retained as a harness failure.

All nine VAD replays finalized once with the existing demo 1800 ms endpoint, RMS threshold 400 and 200 ms pre-roll. “Да” had only 260 ms above threshold. No higher minimum-duration gate was added to discard it. Padding/resampling recovered “Потвърждавам часа” but corrupted “Точно така”; no global change is justified by this corpus. No negative, rejection or ambiguous control became affirmative, but **the question control became affirmative in all three variants**. The question marks in known text are rejected by the application, yet ASR removed this punctuation. This is an actual false-positive acoustic-control failure, not safe general speech acceptance. Prosody/human recognition and broader consent validation remain open.
