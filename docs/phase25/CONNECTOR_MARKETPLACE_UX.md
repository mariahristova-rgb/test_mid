# Catalog and workspace UX

Existing Google admin view hosts the local catalog and synthetic workspace; URL and role guards remain. Four planned provider cards are distinct from existing owner-only Google controls. No unavailable customer connector presents a live Connect action or AVAILABLE claim.

Owner can explicitly open the synthetic workspace, select provider/action checkboxes, save a fixture connection, run private synthetic OAuth, inspect resource IDs, preview permitted actions and disconnect. All states/results say simulated. No vendor page opens or secrets are entered. Mutating previews require a separate synthetic-write consent checkbox. Preview event clock is explicitly 9 October 2030, 15:00–15:30 Europe/Sofia.

Quote form records scoping metadata and says no charge/commercial review. BG/EN labels, native fieldsets, label associations, busy disables, error alerts and polite receipts reuse existing UI. This is a local admin testing experience, not public customer onboarding or a certified provider marketplace.
